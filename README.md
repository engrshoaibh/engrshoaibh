## 🚀 Featured Projects

### ⚡ Download Manager Pro

[![Live Site](https://img.shields.io/badge/Live-downloadmanagerpro.app-success?style=for-the-badge&logo=googlechrome&logoColor=white)](http://downloadmanagerpro.app/) [![Repo](https://img.shields.io/badge/Source-GitHub-121011?style=for-the-badge&logo=github&logoColor=white)](https://github.com/engrshoaibh/Download-Manager)

An open-source, high-performance download manager built as a modern alternative to IDM and Ghost Downloader.

- 🚀 **Rust-based chunked download engine** that splits files into up to 32 concurrent segments for maximum speed
- ⏯️ **Reliable pause and resume** using `.part` metadata tracking, with no data corruption
- 🎥 **YouTube video and audio downloads** powered by `yt-dlp`
- 🧩 **Browser extension** that captures downloads straight into the app
- 🎨 **Modern dark UI** built with Tauri, React, and Tailwind CSS
- 🚦 **Global speed limiter** to keep bandwidth free for other apps

**Tech:** `Rust` · `Tauri` · `React` · `Tailwind CSS` · `Tokio` · `yt-dlp`

🔗 [Live Site](http://downloadmanagerpro.app/) · [Source Code](https://github.com/engrshoaibh/Download-Manager)
